## Changelog

OpenMetadata 2.0.10 is a maintenance release that improves single sign-on (SSO) and Security Assertion Markup Language (SAML) sign-in, including an interactive Test Login for administrators. It encrypts connection secrets that were saved in plain text and rebuilds ingestion images with patched Java and Go runtimes. It also adds Tableau connected app sign-in, dbt Cloud multi-job ingestion, and MicroStrategy column lineage. The release fixes pagination, alert, and MySQL hard delete issues.

### 🔐 Authentication and SSO

This release includes the following SSO and authentication fixes:

- **SSO settings could not be tested with a complete sign-in** [#38197](https://github.com/open-metadata/OpenMetadata/pull/38197), [#38301](https://github.com/open-metadata/OpenMetadata/pull/38301): Administrators can now run an interactive **Test Login** for SAML, confidential OpenID Connect (OIDC), Lightweight Directory Access Protocol (LDAP), and Basic authentication before saving. The check also covers unsaved settings. The session table that Test Login needs is now created by the 2.0.10 upgrade.
- **Keycloak users with roles could not sign in with SAML** [#38447](https://github.com/open-metadata/OpenMetadata/pull/38447): SAML sign-in now accepts an attribute name that the identity provider sends more than once, such as Keycloak's `Role` attribute.
- **Expired SAML identity provider certificates could stop the server from starting** [#38441](https://github.com/open-metadata/OpenMetadata/pull/38441), [#38317](https://github.com/open-metadata/OpenMetadata/pull/38317): The server now starts when every saved certificate has expired, and the SAML callback in the browser no longer fails. The 2.0.10 upgrade also rewrites a stored identity provider certificate as standard Privacy-Enhanced Mail (PEM) text.
- **A failed security settings save was reported as a success** [#38487](https://github.com/open-metadata/OpenMetadata/pull/38487): `update-security-config` now logs the reason and exits with an error. The SAML settings form is now translated, and `providerName` is now required for custom OIDC only.

### 🔌 Connectors and Ingestion

This release includes the following connector and ingestion improvements:

- **Tableau connected app sign-in was not supported** [#38483](https://github.com/open-metadata/OpenMetadata/pull/38483): The Tableau dashboard connection now supports a connected app (direct trust) credential made of a client ID, secret ID, secret value, and username.
- **dbt Cloud ingestion read only one job's artifacts** [#37987](https://github.com/open-metadata/OpenMetadata/pull/37987): You can now list several dbt Cloud job IDs, or ingest all jobs, and the artifacts merge per environment. Models keep the compiled SQL from a full job.
- **Adding a dbt data model removed a table's schema definition** [#38462](https://github.com/open-metadata/OpenMetadata/pull/38462): A table keeps its `schemaDefinition` when dbt ingestion adds a data model, and the next ingestion run restores one that was already lost.
- **MicroStrategy metrics of schema cubes had no column lineage** [#38336](https://github.com/open-metadata/OpenMetadata/pull/38336): Metrics now get column-level lineage through the SQL projection that matches their alias or name, or through the metrics and facts they are built from. Reading this lineage needs Architect read access.
- **A fresh ingestion install could fail with `No module named 'pytz'`** [#38270](https://github.com/open-metadata/OpenMetadata/pull/38270): Ingestion now requires `the `dbt` extra of its data diff dependency and declares `pytz` directly.

### 🛡️ Data Governance

This release includes the following governance fix:

- **Glossary terms that were not Approved could be applied right away** [#38507](https://github.com/open-metadata/OpenMetadata/pull/38507): A write that applies a term that is not **Approved** is now accepted, and the term is held as pending. It is hidden from reads and search until the term is approved, and then it is applied to each asset that holds it.

### 🔗 AI Context and MCP Server

This release includes the following Model Context Protocol (MCP) fix:

- **MCP requests accepted unsupported protocol versions** [#38584](https://github.com/open-metadata/OpenMetadata/pull/38584): The server now returns a 400 Invalid Request response for an unsupported `MCP-Protocol-Version` on `/mcp` requests, except for `initialize`.

### 📣 Alerts and Events

This release includes the following alert fix:

- **Opening a disabled alert's page saved a start position** [#38281](https://github.com/open-metadata/OpenMetadata/pull/38281): Reading an alert's saved position no longer saves one when none exists, so an alert that has never run keeps its correct start.

### ⚙️ Platform and Operations

This release includes the following platform and operations fixes:

- **Hard delete failed on MySQL with `Illegal mix of collations`** [#38442](https://github.com/open-metadata/OpenMetadata/pull/38442): Hard delete of a taggable entity no longer returns a 500 error on MySQL servers whose tables use different collations.
- **Database calls could pin the server's virtual threads** [#38520](https://github.com/open-metadata/OpenMetadata/pull/38520): The server now runs Jdbi 3.49.5, which no longer holds a virtual thread while it waits on the database.

### 🎛️ UI

This release includes the following user interface (UI) improvements:

- **Cursor-paginated lists could show stale or wrong pages** [#38481](https://github.com/open-metadata/OpenMetadata/pull/38481): The 11 cursor-paginated lists now use one URL-driven fetch, reset the page on search and filter changes, and ignore older responses.
- **Data Models and Stored Procedures pagination was out of sync** [#38505](https://github.com/open-metadata/OpenMetadata/pull/38505): The page count no longer includes a phantom page past the last result.
- **The asset header did not show when an asset was last updated at its source** [#38593](https://github.com/open-metadata/OpenMetadata/pull/38593): The header now shows **Updated at source** as relative time, with the exact time on hover. It is hidden when the source reported no update time.

### 🔒 Security

This release includes the following security updates:

- **Connection secrets were still saved in plain text** [#38118](https://github.com/open-metadata/OpenMetadata/pull/38118): SQL Server Integration Services (SSIS) database connections, Qlik Sense certificates, and SAP S/4HANA authentication are now encrypted and masked. So are secrets inside lists, such as MCP server headers.
- **Ingestion images carried an outdated Java runtime and vulnerable Go modules** [#38299](https://github.com/open-metadata/OpenMetadata/pull/38299), [#38242](https://github.com/open-metadata/OpenMetadata/pull/38242): Operator ingestion images now take the latest security-patched Java runtime on every build. The FlightSQL wheel is rebuilt with Go 1.26.11 and patched modules.
- **Static asset paths were not confined to the resource root** [#38590](https://github.com/open-metadata/OpenMetadata/pull/38590): The server now keeps static asset requests inside the resource root.
