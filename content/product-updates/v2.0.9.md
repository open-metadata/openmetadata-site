## Changelog

OpenMetadata 2.0.9 is a maintenance release that improves the MicroStrategy and Sigma connectors and makes ingestion, profiling and sampling more reliable. It also tightens secret masking and authorization. The release fixes several Data Quality, incident and governance workflow issues. It improves search reindexing and UI reliability, and it updates dependencies to address security advisories.

### 🔌 Connectors and Ingestion

- **MicroStrategy ingestion was unreliable and lineage was incomplete** [#37730](https://github.com/open-metadata/OpenMetadata/pull/37730), [#37855](https://github.com/open-metadata/OpenMetadata/pull/37855), [#37945](https://github.com/open-metadata/OpenMetadata/pull/37945), [#37980](https://github.com/open-metadata/OpenMetadata/pull/37980), [#38217](https://github.com/open-metadata/OpenMetadata/pull/38217): The connector now skips documents, parses cube SQL once and routes lineage by project. It adds column-level lineage from cube SQL to data models and reads a report dataset's lineage from its source cube. Reports built on Live cubes now explain where their data comes from.
- **Sigma lineage was missing for elements and formulas** [#37766](https://github.com/open-metadata/OpenMetadata/pull/37766): Sigma ingestion now walks element lineage, lists workbooks across the whole organization and captures formula lineage.
- **dbt meta applied glossary terms that weren't approved** [#37719](https://github.com/open-metadata/OpenMetadata/pull/37719): Only Approved glossary terms are applied from dbt meta.
- **BigQuery DDL cache collided across concurrent datasets** [#38234](https://github.com/open-metadata/OpenMetadata/pull/38234): The DDL cache is now keyed by fully qualified name.
- **MSSQL and AzureSQL profiler SQL altered schema names** [#37789](https://github.com/open-metadata/OpenMetadata/pull/37789): Literal schema names are preserved.
- **Oracle percentage samples were inaccurate** [#37940](https://github.com/open-metadata/OpenMetadata/pull/37940): A new Oracle sampler keeps percentage samples per row.
- **Datalake sampler dropped rows and flattened lists** [#38175](https://github.com/open-metadata/OpenMetadata/pull/38175): Rows with partial nulls are kept and list cells are returned as lists.
- **GCS structured child container metrics were wrong** [#37968](https://github.com/open-metadata/OpenMetadata/pull/37968): Metrics for structured child containers are now computed correctly.
- **Testing a connection from the service page used the wrong runner** [#38159](https://github.com/open-metadata/OpenMetadata/pull/38159): The service's configured runner is now sent.
- **Ingestion could pull an incompatible python-liquid** [#37871](https://github.com/open-metadata/OpenMetadata/pull/37871): python-liquid is capped below version 3.

### ✅ Data Quality, Incidents and Observability

- **Data Quality table totals were inexact** [#37913](https://github.com/open-metadata/OpenMetadata/pull/37913): Exact table totals and related integration fixes are backported to 2.0.
- **Incident cards miscounted open incidents** [#38222](https://github.com/open-metadata/OpenMetadata/pull/38222): The Open incident card now counts Acknowledged and Assigned incidents, and incident cards are described as daily activity.
- **Metrics showed the wrong status and the metrics worker could race** [#38009](https://github.com/open-metadata/OpenMetadata/pull/38009), [#37899](https://github.com/open-metadata/OpenMetadata/pull/37899), [#38130](https://github.com/open-metadata/OpenMetadata/pull/38130): The metrics list shows the real status, and the worker finishes in-flight items before summarizing or resetting for a new run.
- **Data Insights charts drew axis categories they didn't count** [#37898](https://github.com/open-metadata/OpenMetadata/pull/37898): The categorical axis is drawn only from the documents the chart counts. A new `DataInsightsExtension` hook is also available [#37815](https://github.com/open-metadata/OpenMetadata/pull/37815).
- **The alerts page could show an unbounded pending count** [#38094](https://github.com/open-metadata/OpenMetadata/pull/38094): The pending count is now bounded.

### 🏛️ Governance, Tags and Workflows

- **Resolved tag updates left stale tags behind** [#37724](https://github.com/open-metadata/OpenMetadata/pull/37724): Tags that a resolved TagUpdate leaves out are now removed.
- **Tag recognizers could be saved without a supported language** [#37568](https://github.com/open-metadata/OpenMetadata/pull/37568): These recognizers are now rejected.
- **Tag suggestion tasks displayed as description tasks** [#38114](https://github.com/open-metadata/OpenMetadata/pull/38114): Tag suggestion tasks now display as tags.
- **Hard delete removed tags from entities sharing the same FQN** [#38230](https://github.com/open-metadata/OpenMetadata/pull/38230): Tags on other entities with the same FQN are kept.
- **Undone edits could hang workflows and backslash tag renames left stale cache** [#38225](https://github.com/open-metadata/OpenMetadata/pull/38225): Both issues are fixed.
- **Workflow node factories were hard-coded** [#38141](https://github.com/open-metadata/OpenMetadata/pull/38141): Factories are now discovered from the classpath.
- **Lifecycle-only updates changed the version author** [#37995](https://github.com/open-metadata/OpenMetadata/pull/37995): The original author is kept.
- **CSV imports dropped rows and versions** [#38192](https://github.com/open-metadata/OpenMetadata/pull/38192): Imported rows and their versions are kept.
- **Task-created notifications linked to the wrong place** [#38090](https://github.com/open-metadata/OpenMetadata/pull/38090): Notifications now link to the task page.

### 🔐 Security, Authorization and Authentication

- **Secrets could leak in nested schemas and version history** [#37962](https://github.com/open-metadata/OpenMetadata/pull/37962), [#38184](https://github.com/open-metadata/OpenMetadata/pull/38184): Secrets nested in a schema `oneOf` are masked and encrypted, and plain-text secrets left in service version history are masked.
- **Removed policy rules took effect late** [#37996](https://github.com/open-metadata/OpenMetadata/pull/37996): A removed rule now applies on the next authorization decision.
- **The Admin role name could be reused** [#38121](https://github.com/open-metadata/OpenMetadata/pull/38121): The Admin role name is reserved, and the admin flag is labeled separately from roles.
- **Document Store writes were authorized in several places** [#38204](https://github.com/open-metadata/OpenMetadata/pull/38204): Authorization is now enforced in one place.
- **Okta SAML certificates with the organization name as CN were rejected** [#33625](https://github.com/open-metadata/OpenMetadata/pull/33625): These certificates are now accepted.
- **Signup and password-reset hid email delivery failures** [#38232](https://github.com/open-metadata/OpenMetadata/pull/38232): The `424 FAILED_SEND_EMAIL` response is preserved.
- **Dependency and image updates**: CVE dependency floors and a Power BI `.pbit` Zip Slip fix for ingestion [#37861](https://github.com/open-metadata/OpenMetadata/pull/37861), minimatch 11 for GHSA-g3hv-75wg-m249 [#38106](https://github.com/open-metadata/OpenMetadata/pull/38106), BlockEditor mention links opened with `noopener` [#38089](https://github.com/open-metadata/OpenMetadata/pull/38089), and the JDK taken from Corretto 21.0.13.1.2 [#38125](https://github.com/open-metadata/OpenMetadata/pull/38125). SECURITY.md now lists 2.0.x and 1.13.x as supported [#38124](https://github.com/open-metadata/OpenMetadata/pull/38124).

### 🤖 MCP

- **Disabling the MCP Server app required a restart** [#37727](https://github.com/open-metadata/OpenMetadata/pull/37727): MCP stops as soon as the app is disabled.
- **`get_entity_details` without `entityType` or `fqn` failed unclearly** [#38160](https://github.com/open-metadata/OpenMetadata/pull/38160): The request is now rejected with a 400.

### 🔎 Search, Platform and Upgrades

- **The orphan sweep could fail a live reindex job** [#38120](https://github.com/open-metadata/OpenMetadata/pull/38120): The sweep no longer fails a reindex job while it initializes.
- **The 2.0.8 audit cleanup was slow** [#38153](https://github.com/open-metadata/OpenMetadata/pull/38153): The audit log entity-type index is added before the cleanup runs.
- **MySQL 8.4.13 support** [#38172](https://github.com/open-metadata/OpenMetadata/pull/38172): MySQL 8.4.13 is shipped and tested.

### 🖥️ UI

- **Composite unique constraints were indistinguishable** [#38178](https://github.com/open-metadata/OpenMetadata/pull/38178): Composite unique constraints are now shown distinctly.
- **My Tasks widget rendered all cards at once** [#37944](https://github.com/open-metadata/OpenMetadata/pull/37944): Cards mount only when scrolled into view.
- **Context Center article tabs were narrow** [#38193](https://github.com/open-metadata/OpenMetadata/pull/38193): Article tabs are full width, and AskCollate is dropped from the memories subtitle.
